开发者面板

面板用于审查进行中的对局：谜题、汤面、汤底与全部对话（含私聊），辅助做违规词与合规审查。
进入需要本机私钥生成的开发者密钥；私钥只保存在你的电脑上，不会上传服务器。

密钥是怎么来的？

在项目目录执行 npm run dev:keygen：脚本把私钥写到本机 .keys/dev-private.pem（已在 .gitignore 中），并输出一串开发者密钥。

服务器只保存公钥（src/dev-public-key.js），用它验签；仅凭公钥无法反推私钥。
